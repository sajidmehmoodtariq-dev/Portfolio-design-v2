## 1. The idea in one paragraph

The website is a **guided tour through a system diagram**. My isometric "system" (six modules: Contact, About, Work, Now, Experience, Skills) stays **fixed on screen** while you scroll. Scrolling moves a camera over it: it **zooms into one module at a time** (the module grows big), and that chapter's content appears next to it. Then it zooms out and into the next one. At the end it zooms all the way out for Contact. This growing and shrinking of the diagram while scrolling is the signature effect, and it must feel smooth.

- **Next.js** (App Router, latest stable) + **TypeScript** + **Tailwind CSS**
- **GSAP + ScrollTrigger** for the tour: **one** pinned, scrubbed timeline. GSAP is free, including ScrollTrigger.
- **next-themes** for dark/light mode (dark is the default)
- **react-icons** for real tech logos (Simple Icons `si`; Devicon `di` as a fallback)
- **lucide-react** for small UI icons
- Fonts from npm: `@fontsource-variable/hubot-sans` (big headings), `@fontsource-variable/mona-sans` (text), `@fontsource/monaspace-neon` (small labels)
- **Do NOT use:** Three.js / WebGL, Lenis or any smooth-scroll library, Framer Motion scroll hooks, or particle libraries. These caused the lag last time. Native browser scrolling + one GSAP timeline only.

## 6. The scroll tour (the signature effect)

### 6.1 Structure
- The home page is one section `#tour` with a full-screen **stage** (`100svh`). It is **pinned** by ScrollTrigger while you scroll through roughly **800vh**.
- Inside the stage: the SVG diagram in a wrapper `div.camera`, plus one **content layer per chapter** (absolutely positioned HTML).
- **One GSAP timeline** with `scrollTrigger: { trigger: "#tour", pin: true, scrub: 0.6, start: "top top", end: "+=800%" }`. Add **labels** for each chapter so the rail and buttons can jump to them (`scrollTo` the label position).

### 6.2 The camera
The camera zooms by animating **only** `transform: translate(x, y) scale(s)` on `div.camera` (`transform-origin: 0 0`). For each chapter, compute `x` and `y` so the target module's center lands at the screen position below. Use percentages of the viewport, so it works at any size.

| Chapter | Target | Scale | Module center lands at | Content | Match image |
|---|---|---|---|---|---|
| 1 Load / Hero | whole diagram | 1.0 | diagram centered at 72% x, 50% y | hero text on the left | frame 1 |
| 2 About | About module | 3.4 | 30% x, 58% y | About content on the right | frame 2 |
| 3 Work | Work module | 2.2 | 25% x, 67% y | "SELECTED WORK●" top-left + project card on the right | frame 3 |
| 4 Experience | Experience module | 3.0 | 30% x, 58% y | experience list on the right | frame 4 |
| 5 Tools | Skills module | 3.1 | 50% x, 40% y | title on top, logo strip at the bottom | frame 5 |
| 6 Contact | whole diagram | 0.8 | diagram centered at 76% x, 52% y | contact content on the left | frame 6 |

**Timing:** each chapter gets a **hold** (content fully visible, camera still) and a **move** to the next one. About 40% of each chapter's scroll is the move and 60% is the hold, so content stays readable. Ease the moves with `power2.inOut`.

**During each move:**
- The old content fades out and moves up 24px; the new content fades in from 24px below (titles first, then text, then cards, with a 0.06 stagger).
- A soft gradient "veil" (`--bg` → transparent) fades in on the content side, so text stays readable over the big module (see frames 2–5).
- Labels fade out when leaving the overview and fade back in for Contact.

## 7. Smoothness rules (MUST follow)

### 7.1 Do
- **One** ScrollTrigger timeline for the whole tour. No other scroll listeners.
- Animate **only `transform` and `opacity`**. Put `will-change: transform` on `.camera` and the content layers.
- Draw the SVG once. During scroll, never change SVG attributes, re-render React state, or recalculate layout.
- Packets: CSS animations. **Pause them while the camera is moving** (toggle a class at the move's start and end) and when the tab is hidden.
- Pre-blurred glows (static blurred shapes). Never animate `filter`, `box-shadow` or `backdrop-filter` while scrolling.
- `scrub: 0.6` for a little smoothing. Use `ScrollTrigger.config({ ignoreMobileResize: true })`.
- Use `gsap.matchMedia()` so the tour only runs on screens ≥ 900px wide without reduced motion (see 7.2).
- Clean up on unmount (`useGSAP` from `@gsap/react` or `ctx.revert()`).

### 7.2 Mobile and reduced motion
On screens under 900px wide, or when `prefers-reduced-motion` is on, **don't pin or zoom**. Show the chapters as normal stacked sections:
- The hero with the full diagram below the text (static, small).
- Each chapter as a section: a **cropped static view** of its module (the same SVG, scaled with CSS) on top, then the content.
- Work: the 3 project cards stacked.
- Simple fade-up reveals only (IntersectionObserver + CSS transition).

### 7.3 Test it
- Run `npm run build && npm start` (production mode, not dev).
- Use Playwright with Chrome to scroll slowly through the whole tour while recording a performance trace. Report the **average FPS and any long frames over 50ms**. Target: **55–60 fps** on a normal laptop.
- If it's under target, simplify the diagram (fewer packets, smaller shadows) until it passes, and tell me what you changed.

// create_snapshot.mjs

import fs from 'fs/promises';
import path from 'path';

// --- CONFIGURATION ---
const ROOT_DIRECTORY = '.';
const OUTPUT_FILE = 'project_snapshot.txt';

// Critical config files to always prepend at the top for context
const CRITICAL_FILES = [
  'package.json', 'tsconfig.json', 'next.config.mjs', 
  'next.config.js', 'postcss.config.js', 'tailwind.config.js'
];

// -- 🚫 EXCLUSIONS --

// Ignore by exact name (applies to files and folders EVERYWHERE in the tree)
const IGNORE_NAMES = [
  'node_modules', '.git', '.next', 'out', 'dist', 'build', '.vscode', '.idea',
  'pnpm-lock.yaml', 'package-lock.json', 'yarn.lock',
  '.env', '.env.local', '.env.production', '.env.development',
  OUTPUT_FILE,
  '__pycache__',
  'modules',
  'photos', 
  'records',
  '.gitignore'
];

// Ignore by relative path from the root (matches specific folders or files)
// Always use forward slashes (e.g., 'public/images')
const IGNORE_PATHS = [
  'public/images',
  'public/fonts'
];


// -- ✅ INCLUSIONS --

// Include files by their extension
const INCLUDE_EXTENSIONS = [
  '.js', '.ts', '.jsx', '.tsx',    // Scripts
  '.json', '.html',                // Configs
  '.scss', '.css', '.module.scss', '.tsx', // Styles
  '.md', '.mdx',                   // Documentation
  '.mjs', '.cjs', '.webmanifest',  // JS Modules
  '.svg', '.py', '.go', '.rs',     // Code / SVG
  '.java', '.cpp', '.c', '.h', '.asm'
];

// Include specific files by exact name (useful for files without extensions)
const INCLUDE_FILES = [
  'Dockerfile',
  'Makefile',
  '.prettierrc',
  '.eslintrc.json'
];

// Force include ALL files within specific directory paths (ignores extension checks)
// Always use forward slashes (e.g., 'src/special_folder')
const INCLUDE_PATHS = [
  // 'docs/raw_assets'
];

// --- SCRIPT LOGIC ---

// Helper function to determine if a file/folder should be ignored
function isIgnored(name, relativePath) {
  if (IGNORE_NAMES.includes(name)) return true;
  
  for (const ignorePath of IGNORE_PATHS) {
    // Check if it's the exact path or a sub-path of the ignored path
    if (relativePath === ignorePath || relativePath.startsWith(ignorePath + '/')) {
      return true;
    }
  }
  return false;
}

// Helper function to determine if a file should be included in the source dump
function isIncluded(name, relativePath) {
  const ext = path.extname(name);
  if (INCLUDE_EXTENSIONS.includes(ext)) return true;
  if (INCLUDE_FILES.includes(name)) return true;
  
  for (const includePath of INCLUDE_PATHS) {
    if (relativePath === includePath || relativePath.startsWith(includePath + '/')) {
      return true;
    }
  }
  return false;
}

async function generateSnapshot() {
  console.log('🚀 Starting to generate project snapshot...');
  try {
    // Clear the output file if it exists, or create it.
    await fs.writeFile(OUTPUT_FILE, '');

    // 1. Write a header
    await appendToOutput(`--- Project Snapshot ---`);
    await appendToOutput(`--- Generated on: ${new Date().toUTCString()} ---\n`);

    // 2. Add critical configuration files first for context
    await appendToOutput(`\n\n=============== 📌 CRITICAL CONFIG FILES ===============\n`);
    for (const file of CRITICAL_FILES) {
      try {
        const content = await fs.readFile(path.join(ROOT_DIRECTORY, file), 'utf-8');
        await appendToOutput(`\n--- FILE: ${file} ---\n`);
        await appendToOutput(content);
        await appendToOutput(`\n--- END OF FILE: ${file} ---\n`);
      } catch (error) {
        if (error.code !== 'ENOENT') {
            console.warn(`⚠️  Could not read critical file: ${file}`);
        }
      }
    }

    // 3. Generate and append the directory tree
    await appendToOutput(`\n\n=============== 🌳 DIRECTORY STRUCTURE ===============\n`);
    const tree = await generateTree(ROOT_DIRECTORY, '');
    await appendToOutput(tree);

    // 4. Append the content of all other relevant files
    await appendToOutput(`\n\n=============== 📄 SOURCE CODE & FILES ===============\n`);
    await processDirectory(ROOT_DIRECTORY);

    console.log(`✅ Success! Project snapshot saved to ${OUTPUT_FILE}`);

  } catch (error) {
    console.error('❌ An error occurred while generating the snapshot:', error);
  }
}

async function appendToOutput(content) {
  await fs.appendFile(OUTPUT_FILE, content + '\n');
}

async function generateTree(dir, prefix) {
  let treeString = '';
  try {
    const entries = await fs.readdir(dir, { withFileTypes: true });
    
    // Filter out ignored items
    const filteredEntries = entries.filter(entry => {
      const fullPath = path.join(dir, entry.name);
      const relativePath = path.relative(ROOT_DIRECTORY, fullPath).replace(/\\/g, '/');
      return !isIgnored(entry.name, relativePath);
    });

    for (const [index, entry] of filteredEntries.entries()) {
      const connector = index === filteredEntries.length - 1 ? '└── ' : '├── ';
      treeString += `${prefix}${connector}${entry.name}\n`;
      
      if (entry.isDirectory()) {
        const newPrefix = prefix + (index === filteredEntries.length - 1 ? '    ' : '│   ');
        const fullPath = path.join(dir, entry.name);
        treeString += await generateTree(fullPath, newPrefix);
      }
    }
  } catch (error) {
    // Ignore errors for directories we can't read (e.g., permissions)
  }
  return treeString;
}

async function processDirectory(dir) {
  try {
    const entries = await fs.readdir(dir, { withFileTypes: true });
    for (const entry of entries) {
      const fullPath = path.join(dir, entry.name);
      // Normalize slashes for consistency across OSes (Windows/Mac/Linux)
      const relativePath = path.relative(ROOT_DIRECTORY, fullPath).replace(/\\/g, '/');

      // Check Exclusions
      if (isIgnored(entry.name, relativePath)) {
        continue;
      }

      if (entry.isDirectory()) {
        await processDirectory(fullPath);
      } else if (entry.isFile() && isIncluded(entry.name, relativePath)) {
        try {
          const content = await fs.readFile(fullPath, 'utf-8');
          await appendToOutput(`\n--- FILE: ${relativePath} ---`);
          await appendToOutput(content);
          await appendToOutput(`\n--- END OF FILE: ${relativePath} ---\n`);
        } catch (readError) {
          console.warn(`⚠️  Could not read file: ${relativePath}`);
        }

"use client";

import { useEffect } from "react";

// Small screens / reduced motion: fades each ".reveal" element up the first time it
// scrolls into view, using one IntersectionObserver and a CSS transition.
export default function RevealObserver() {
  useEffect(() => {
    const els = document.querySelectorAll(".reveal:not(.is-in)");
    const io = new IntersectionObserver(
      (entries) => {
        entries.forEach((entry) => {
          if (entry.isIntersecting) {
            entry.target.classList.add("is-in");
            io.unobserve(entry.target);
          }
        });
      },
      { rootMargin: "0px 0px -8% 0px" },
    );
    els.forEach((el) => io.observe(el));
    return () => io.disconnect();
  }, []);

  return null;
}

// The two "cameras" the tour moves around (desktop only):
// - .camera holds the diagram, drawn 3.4× bigger than needed so it stays sharp when zoomed in
// - .label-camera holds the labels and hover card at normal size (they only show zoomed out)
export default function CameraRig() {
  const [active, setActive] = useState<ModuleId | null>(null);
  const svgRef = useRef<SVGSVGElement>(null);

  // Hover highlight: toggle classes directly, so the big SVG is not re-rendered by React
  useEffect(() => {
    const svg = svgRef.current;
    if (!svg) return;
    if (active) svg.setAttribute("data-active", active);
    else svg.removeAttribute("data-active");
    svg.querySelectorAll<SVGGElement>("[data-mod]").forEach((g) => {
      g.classList.toggle("is-active", g.dataset.mod === active);
    });
  }, [active]);

  // Wraps every module in a focusable button with hover + click handlers (stable, so the art renders once)
  const wrapModule = useCallback(
    (m: ModuleInfo, shape: ReactNode) => (
      <g
        data-mod={m.id}
        className="mod cursor-pointer outline-none"
        role="button"
        tabIndex={0}
        aria-label={`${m.label.toLowerCase()}: ${m.sentence} Opens the ${m.chapter} chapter.`}
        onMouseEnter={() => setActive(m.id)}
        onMouseLeave={() => setActive(null)}
        onFocus={() => setActive(m.id)}
        onBlur={() => setActive(null)}
        onClick={() => goToChapter(m.chapter)}
        onKeyDown={(e: KeyboardEvent) => {
          if (e.key === "Enter" || e.key === " ") {
            e.preventDefault();
            goToChapter(m.chapter);
          }
        }}
      >
        <g className="mod-lift">{shape}</g>
      </g>
    ),
    [],
  );

  const info = MODULES.find((m) => m.id === active);

  return (
    <div className="camera-rig" aria-label="System diagram: a map of this site" role="group">
      <div className="camera">
        <svg
          ref={svgRef}
          viewBox={`0 0 ${VIEW_W} ${VIEW_H}`}
          className="diagram absolute inset-0 h-full w-full overflow-visible"
        >
          <DiagramArt wrapModule={wrapModule} />
        </svg>
        <Packets />
      </div>

      <div className="label-camera pointer-events-none">
        <svg
          viewBox={`0 0 ${VIEW_W} ${VIEW_H}`}
          className="absolute inset-0 h-full w-full overflow-visible"
          aria-hidden
        >
          <DiagramLabels />
        </svg>
        {info ? (
          <div

// Tiny helpers that draw "soft" isometric shapes in SVG.
// Every shape is positioned by the centre of its footprint on the ground (cx, cy).
// Corners are softened by stroking each face with its own colour and round joins.
import type { LucideIcon } from "lucide-react";

type Pt = [number, number];
const K = 1.732; // an isometric square is √3 times wider than it is tall
export const RY = 0.577; // an isometric circle is 0.577 times as tall as it is wide

const pts = (list: Pt[]) => list.map(([x, y]) => `${x.toFixed(1)},${y.toFixed(1)}`).join(" ");

// Fill + same-colour stroke = rounded corners
const face = (color: string, round: number) => ({
  fill: color,
  stroke: color,
  strokeWidth: round,
  strokeLinejoin: "round" as const,
});

export const TOP = "var(--mod-top)";
export const SIDE_L = "var(--mod-side-l)";
export const SIDE_R = "var(--mod-side-r)";
export const BASE_TOP = "var(--mod-base-top)";
export const BASE_L = "var(--mod-base-l)";
export const BASE_R = "var(--mod-base-r)";
export const ORANGE = "var(--accent)";
export const ORANGE_L = "var(--accent-side-1)";
export const ORANGE_R = "var(--accent-side-2)";

/* ---------------- Soft shadow (pre-blurred: a radial gradient, no filter) ---------------- */
export function Shadow({ cx, cy, rx, ry }: { cx: number; cy: number; rx: number; ry: number }) {
  return <ellipse cx={cx + rx * 0.08} cy={cy + ry * 0.25} rx={rx} ry={ry} fill="url(#soft-shadow)" />;
}

/* ---------------- Box (rounded cube / slab) ---------------- */
export function topRhombus(cx: number, cy: number, a: number) {
  return pts([
    [cx, cy - a],
    [cx + K * a, cy],
    [cx, cy + a],
    [cx - K * a, cy],
  ]);
}

type BoxProps = {
  cx: number;
  cy: number;
  a: number; // half size of the square footprint
  h: number; // height
  top?: string;
  left?: string;
  right?: string;
  round?: number;
};

export function IsoBox({ cx, cy, a, h, top = TOP, left = SIDE_L, right = SIDE_R, round = 10 }: BoxProps) {
  const W: Pt = [cx - K * a, cy];
  const S: Pt = [cx, cy + a];
  const E: Pt = [cx + K * a, cy];
  return (
    <g>
      <polygon points={pts([W, S, [S[0], S[1] - h], [W[0], W[1] - h]])} style={face(left, round)} />
      <polygon points={pts([S, E, [E[0], E[1] - h], [S[0], S[1] - h]])} style={face(right, round)} />
      <polygon points={topRhombus(cx, cy - h, a)} style={face(top, round)} />
    </g>
  );
}

/* ---------------- Cylinder (puck / disc) ---------------- */
type CylProps = { cx: number; cy: number; rx: number; h: number; top?: string; side?: string };

export function IsoCyl({ cx, cy, rx, h, top = TOP, side = "url(#side-grad)" }: CylProps) {
  const ry = rx * RY;
  return (
    <g>
      <path
        d={`M${cx - rx},${cy - h} L${cx - rx},${cy} A${rx},${ry} 0 0 0 ${cx + rx},${cy} L${cx + rx},${cy - h} Z`}
        style={{ fill: side }}
      />
      <ellipse cx={cx} cy={cy - h} rx={rx} ry={ry} style={{ fill: top }} />
    </g>
  );
}

// The front half of an ellipse, used for the glowing seams on stacked cylinders
export function frontArc(cx: number, cy: number, rx: number) {
  return `M${cx - rx},${cy} A${rx},${rx * RY} 0 0 0 ${cx + rx},${cy}`;
}

/* ---------------- Hexagon plate ---------------- */
type HexProps = { cx: number; cy: number; r: number; h: number; top?: string; left?: string; right?: string };

export function hexPoints(cx: number, cy: number, r: number): Pt[] {
  // a regular hexagon on the ground, projected to isometric screen space
  return Array.from({ length: 6 }, (_, i) => {
    const t = ((i * 60 + 15) * Math.PI) / 180;
    const x = r * Math.cos(t);
    const y = r * Math.sin(t);
    return [cx + (x - y) * 0.866, cy + (x + y) * 0.5] as Pt;
  });
}

export function IsoHex({ cx, cy, r, h, top = TOP, left = SIDE_L, right = SIDE_R }: HexProps) {
  const base = hexPoints(cx, cy, r);
  const sides = base.map((p, i) => {
    const q = base[(i + 1) % 6];
    if ((p[1] + q[1]) / 2 <= cy) return null; // back sides are hidden
    const color = (p[0] + q[0]) / 2 < cx ? left : right;
    return <polygon key={i} points={pts([p, q, [q[0], q[1] - h], [p[0], p[1] - h]])} style={face(color, 6)} />;
  });
  return (
    <g>
      {sides}
      <polygon points={pts(base.map(([x, y]) => [x, y - h] as Pt))} style={face(top, 6)} />
    </g>
  );
}

/* ---------------- Icon laid on a top face ---------------- */
// Lucide icons are drawn upright and squashed a little so they sit on the surface.
export function TopIcon({
  x,
  y,
  size = 22,
  color,
  icon: Icon,
  strokeWidth = 1.7,
}: {
  x: number;
  y: number;
  size?: number;
  color: string;
  icon: LucideIcon;
  strokeWidth?: number;
}) {
  return (
    <g transform={`translate(${x} ${y}) scale(1 0.78) translate(${-size / 2} ${-size / 2})`} style={{ color }}>
      <Icon size={size} strokeWidth={strokeWidth} aria-hidden />
    </g>
  );
}

/* ---------------- Glow (pre-blurred radial gradient) ---------------- */
export function Glow({ cx, cy, r, white = false }: { cx: number; cy: number; r: number; white?: boolean }) {
  return <circle cx={cx} cy={cy} r={r} fill={white ? "url(#glow-white)" : "url(#glow-orange)"} />;
}

// Small glowing dots that travel along the cables in a loop.

          const style = {
            offsetPath: n === 0 ? forward : backward,

            <span key={`${i}-${n}`} className={`packet ${n === 0 ? "packet-white" : "packet-orange"}`} style={style} />
          );
        });
      })}
    </div>
  );
}

  const rail = gsap.utils.toArray<HTMLElement>(document.querySelectorAll("[data-rail]"));

  // Sizes are read from the stage; they are re-read whenever ScrollTrigger refreshes (resize)
  const vw = () => stage.clientWidth;
  const vh = () => stage.clientHeight;
  const unit = () => Math.min(vw() / 1440, vh() / 900); // screen px per diagram unit at zoom 1
  const setSize = () => tour.style.setProperty("--k", String(unit()));
  setSize();
  ScrollTrigger.addEventListener("refreshInit", setSize);

  // Camera transform that puts shot.target at shot.at on screen
  const camX = (s: Shot) => () => s.at[0] * vw() - s.scale * unit() * s.target[0];
  const camY = (s: Shot) => () => s.at[1] * vh() - s.scale * unit() * s.target[1];
  const cameraVars = (s: Shot) => ({ x: camX(s), y: camY(s), scale: s.scale / R });
  const labelVars = (s: Shot) => ({ x: camX(s), y: camY(s), scale: s.scale, opacity: s.labels });

  const tl = gsap.timeline({
    defaults: { ease: "none" },
    scrollTrigger: {
      trigger: tour,
      pin: true,
      scrub: 0.6,
      start: "top top",
      end: "+=800%",
      invalidateOnRefresh: true,
    },
  });

  // Starting state: the overview with the hero text
  tl.set(camera, cameraVars(SHOTS.hero), 0);
  tl.set(labelCam, labelVars(SHOTS.hero), 0);
  tl.set([veils.right, veils.top, veils.bottom], { opacity: 0 }, 0);
  tl.set(cards, { opacity: 0 }, 0);

  let t = 0;
  const holdMiddle: Partial<Record<ChapterId, number>> = {};
  const moves: [number, number][] = [];
  const switchAt: [ChapterId, number][] = [["hero", 0]];

  // A move of the camera from one shot to another, starting at time `t`
  function moveCamera(shot: Shot) {
    const ease = "power2.inOut";
    tl.to(camera, { ...cameraVars(shot), duration: MOVE, ease }, t);
    tl.to(labelCam, { ...labelVars(shot), duration: MOVE, ease }, t);
    tl.to(veils.right, { opacity: shot.veil.right, duration: MOVE }, t);
    tl.to(veils.top, { opacity: shot.veil.top, duration: MOVE }, t);
    tl.to(veils.bottom, { opacity: shot.veil.bottom, duration: MOVE }, t);
    moves.push([t, t + MOVE]);
  }

  // Old content fades out and up; new content fades in from below (titles, text, then cards)
  function swapContent(outEls: HTMLElement[], inEls: HTMLElement[]) {
    tl.to(outEls, { opacity: 0, y: -24, duration: MOVE * 0.45, stagger: 0.03, ease: "power1.in" }, t);
    tl.fromTo(
      inEls,
      { opacity: 0, y: 24 },
      { opacity: 1, y: 0, duration: MOVE * 0.5, stagger: 0.06, ease: "power2.out", immediateRender: false },
      t + MOVE * 0.45,
    );
  }

  function hold(id: ChapterId) {
    holdMiddle[id] = t + HOLD / 2;
    tl.addLabel(id, t + HOLD / 2);
    t += HOLD;
  }

  // Which elements fade in/out for each chapter (Work also has its first/last card)
  const inItems = (id: ChapterId) =>
    id === "work" ? [...items(id).slice(0, 2), cards[0], ...items(id).slice(2)] : items(id);
  const outItems = (id: ChapterId) => (id === "work" ? [...items(id), cards[cards.length - 1]] : items(id));

  hold("hero");
  const order = CHAPTERS.map((c) => c.id);
  for (let i = 1; i < order.length; i++) {
    const from = order[i - 1];
    const to = order[i];
    moveCamera(SHOTS[to]);
    swapContent(outItems(from), inItems(to));
    switchAt.push([to, t + MOVE / 2]);
    t += MOVE;
    hold(to);

    // Inside Work: step through the projects. Each next card slides in from the right,
    // the camera zooms in a little more (2.2 → 2.35 → 2.5).
    if (to === "work") {
      for (let p = 1; p < cards.length; p++) {
        moveCamera({ ...SHOTS.work, scale: SHOTS.work.scale + 0.15 * p });
        tl.to(cards[p - 1], { x: -140, opacity: 0, duration: MOVE * 0.7, ease: "power2.in" }, t);
        tl.fromTo(
          cards[p],
          { x: 140, opacity: 0 },
          { x: 0, opacity: 1, duration: MOVE * 0.7, ease: "power2.out", immediateRender: false },
          t + MOVE * 0.3,
        );
        tl.to(dots[p - 1], { opacity: 0, duration: MOVE * 0.5 }, t + MOVE * 0.25);
        tl.to(dots[p], { opacity: 1, duration: MOVE * 0.5 }, t + MOVE * 0.25);
        t += MOVE;
        t += HOLD;
      }
    }
  }

  // ---- Gentle parallax in the overview (max 8px), transform only ----
  const parallaxX = gsap.quickTo(rig, "x", { duration: 0.6, ease: "power3.out" });
  const parallaxY = gsap.quickTo(rig, "y", { duration: 0.6, ease: "power3.out" });
  function onMouseMove(e: MouseEvent) {
    if (!overview) return;
    parallaxX((e.clientX / window.innerWidth - 0.5) * 16);
    parallaxY((e.clientY / window.innerHeight - 0.5) * 16);
  }
  stage.addEventListener("mousemove", onMouseMove);

  // ---- Small DOM updates from the timeline (only when something changes) ----
  let lastActive: ChapterId | null = null;
  let lastMoving: boolean | null = null;
  let overview = true;

  function onUpdate() {
    const time = tl.time();
    const moving = moves.some(([a, b]) => time > a + 0.002 && time < b - 0.002);
    if (moving !== lastMoving) {
      stage.classList.toggle("is-moving", moving); // pauses the packets
      lastMoving = moving;
    }
    let active: ChapterId = "hero";
    for (const [id, at] of switchAt) if (time >= at) active = id;
    if (active !== lastActive) {
      tour.querySelectorAll<HTMLElement>("[data-chapter]").forEach((el) => {
        el.classList.toggle("is-active", el.dataset.chapter === active);
      });
      rail.forEach((el) => el.classList.toggle("is-active", el.dataset.rail === active));
      lastActive = active;
    }
    const isOverview = !moving && (active === "hero" || active === "contact");
    if (isOverview !== overview) {
      overview = isOverview;
      stage.toggleAttribute("data-overview", isOverview);
      if (!isOverview) {
        parallaxX(0);
        parallaxY(0);
      }
    }
  }
  tl.eventCallback("onUpdate", onUpdate);
  stage.setAttribute("data-overview", "");
  onUpdate();

  // ---- Jumping to chapters (rail, buttons, module clicks) ----
  const st = tl.scrollTrigger!;
  const scrollFor = (id: ChapterId) => st.start + ((st.end - st.start) * (holdMiddle[id] ?? 0)) / tl.duration();
  const jumpTo = (id: ChapterId, smooth = true) =>
    window.scrollTo({ top: scrollFor(id), behavior: smooth ? "smooth" : "auto" });
  setChapterJumper((id) => jumpTo(id));

  // Keyboard users: focusing something inside a hidden chapter brings that chapter on screen
  function onFocusIn(e: FocusEvent) {
    const chapter = (e.target as HTMLElement).closest<HTMLElement>("[data-chapter]");
    const id = chapter?.dataset.chapter as ChapterId | undefined;
    if (id && id !== lastActive) jumpTo(id, false);
  }
  tour.addEventListener("focusin", onFocusIn);

  // ---- Pause the packets while the tab is hidden ----
  const onVisibility = () => stage.classList.toggle("is-hidden", document.hidden);
  document.addEventListener("visibilitychange", onVisibility);

  // Open the page at a chapter when the URL has a #hash (e.g. /#contact)
  const hash = window.location.hash.slice(1) as ChapterId;
  if (CHAPTERS.some((c) => c.id === hash)) {
    requestAnimationFrame(() => jumpTo(hash, false));
  }

  // Clean-up when leaving the tour (unmount or the screen gets small)
  return () => {
    ScrollTrigger.removeEventListener("refreshInit", setSize);
    tour.removeEventListener("focusin", onFocusIn);
    stage.removeEventListener("mousemove", onMouseMove);
    document.removeEventListener("visibilitychange", onVisibility);
    setChapterJumper(null);
    stage.classList.remove("is-moving", "is-hidden");
    stage.removeAttribute("data-overview");
    tour.querySelectorAll("[data-chapter]").forEach((el) => el.classList.remove("is-active"));
  };
}

export default function Tour() {
  const ref = useRef<HTMLElement>(null);

  useGSAP(
    () => {
      ScrollTrigger.config({ ignoreMobileResize: true });
      const mm = gsap.matchMedia();

      return () => mm.revert();
    },
    { scope: ref },
  );

  return (
    <section id="tour" ref={ref} aria-label="A guided tour of my work">
      <DiagramDefs />
      <div className="stage">
        <CameraRig />
        <div aria-hidden className="veil veil-right" />
        <div aria-hidden className="veil veil-top" />
        <div aria-hidden className="veil veil-bottom" />
        <HeroChapter />
        <AboutChapter />
        <WorkChapter />
        <ExperienceChapter />
        <ToolsChapter />
        <ContactChapter />
      </div>
    </section>
  );
}

import Link from "next/link";
import { ArrowDown, ArrowRight, ArrowUpRight } from "lucide-react";
import type { MouseEvent, ReactNode } from "react";

export type Arrow = "right" | "down" | "external" | "none";

type ButtonProps = {
  variant?: "primary" | "secondary";
  size?: "md" | "sm";
  arrow?: Arrow;
  href?: string;
  onClick?: (e: MouseEvent<HTMLElement>) => void;
  children: ReactNode;
  className?: string;
  ariaLabel?: string;
};

// The small arrow after the button text. It moves 3px on hover (see globals.css).
function ArrowIcon({ arrow }: { arrow: Arrow }) {
  if (arrow === "right") return <ArrowRight aria-hidden size={16} className="arrow-right" />;
  if (arrow === "down") return <ArrowDown aria-hidden size={16} className="arrow-down" />;
  if (arrow === "external") return <ArrowUpRight aria-hidden size={16} className="arrow-up-right" />;
  return null;
}

// One pill button. Renders a link when `href` is given, otherwise a <button>.
export default function Button({
  variant = "primary",
  size = "md",
  arrow = "none",
  href,
  onClick,
  children,
  className = "",
  ariaLabel,
}: ButtonProps) {
  const classes = `btn btn-${variant} ${size === "sm" ? "btn-sm" : ""} ${className}`;
  const content = (
    <>
      {children}
      <ArrowIcon arrow={arrow} />
    </>
  );

  if (href) {
    const isExternal = href.startsWith("http");
    const isPlain = isExternal || href.startsWith("mailto:") || href.startsWith("#") || href.endsWith(".pdf");
    if (isPlain) {
      return (
        <a
          href={href}
          onClick={onClick}
          className={classes}
          aria-label={ariaLabel}
          {...(isExternal ? { target: "_blank", rel: "noreferrer" } : {})}
        >
          {content}
        </a>
      );
    }
    return (
      <Link href={href} onClick={onClick} className={classes} aria-label={ariaLabel}>
        {content}
      </Link>
    );
  }

  return (
    <button type="button" onClick={onClick} className={classes} aria-label={ariaLabel}>
      {content}
    </button>
  );
}

// Shared helpers for jumping between the chapters of the tour.

export const CHAPTERS = [
  { id: "hero", name: "Start" },
  { id: "about", name: "About" },
  { id: "work", name: "Work" },
  { id: "experience", name: "Experience" },
  { id: "tools", name: "Tools" },
  { id: "contact", name: "Contact" },
] as const;

export type ChapterId = (typeof CHAPTERS)[number]["id"];

// While the pinned tour is running, it registers a function that scrolls to a chapter's
// place on the timeline. Without the tour (mobile / reduced motion) we scroll to the section.
let jumper: ((id: ChapterId) => void) | null = null;

export function setChapterJumper(fn: ((id: ChapterId) => void) | null) {
  jumper = fn;
}

export function goToChapter(id: ChapterId) {
  if (jumper) {
    jumper(id);
    return;
  }
  const reduce = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  document.getElementById(id)?.scrollIntoView({ behavior: reduce ? "auto" : "smooth", block: "start" });
}
